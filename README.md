## Youtube clone Project

To run the back end: npm start
To run front end: npm run dev

# Git Hub

Front end: https://github.com/jyothsna30-design/youtube-clone
Backend:https://github.com/jyothsna30-design/youtubeclonebackend 

# youtube-clone front end:
 Home.jsx - side bar and homepage
 homepage.jsx - displays all videos
 Login.jsx - login form 
 Navbar.jsx - top navigation bar
 Profile.jsx - channel page
 sidenavbar.jsx - side navigation bar hamburger
 signup.jsx - signup page
 video .jsx - to display single video
 videoupload.jsx - upload video form
 app.jsx - routes to all components


 BackEnd:
  Controllers 
   User, comment and video controllers for signin,login, fetching videos, adding comments
  Models:
   User, comment and video schemas and models
  Routes:
   User, comment and video routers 
  authentication.js:
    For login, generating tokens and verifying it
